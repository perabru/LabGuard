    FONTE E CONTROLE

    Estado da conexão

    Não identificou a rede? Ver passo a passo
    1. Confirme que o computador ou servidor está conectado à rede do laboratório e confira o modo ativo. Uma leitura em demonstração usa dados fictícios.
    2. Sem IP ou gateway? No próprio host do servidor, consulte ipconfig /all no Windows ou ip -4 address show up e ip -4 route show default no Linux. O inventário local cobre IPv4 privada; IPv6 e IP público não aparecem nesta edição.
    3. Poucos dispositivos ou MAC vazio? A tabela local é um cache parcial. O MAC do próprio computador pode ficar vazio; confirme os alunos no painel autorizado do roteador. Wi-Fi de convidados, isolamento, VLAN e NAT podem limitar a lista.
    4. Modelo desconhecido? Confira etiqueta, modelo e firmware com a TI. A operadora e o MAC não comprovam uma integração compatível.
    5. Falha de acesso ao equipamento? Confira IP, porta, certificado, API e permissões. Preserve a validação HTTPS. Corrija a causa e confira o resultado com a TI. Este guia não executa comandos nem altera configurações. O modo avançado com gateway pode reconciliar políticas existentes durante a leitura; siga o procedimento desse modo.

    O servidor consulta a rede do host onde está instalado, que pode ser diferente da rede deste navegador. Não compartilhe senhas, tokens ou chaves. Abrir guia completo de identificação.
