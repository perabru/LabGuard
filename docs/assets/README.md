# Imagens do manual

As capturas mostram a interface real do LabGuard 1.4 em ambiente de demonstração, com dados fictícios e sem conexão ou alteração em uma rede real. Os recortes removem o desktop e as janelas ao fundo. A faixa amarela identifica a natureza de cada exemplo.

| Arquivo | Tela |
| --- | --- |
| `visao_geral.png` | Visão geral e indicadores operacionais |
| `maquinas.png` | Máquinas observadas e ações administrativas |
| `sites_ia.png` | Domínios e perfil de bloqueio de IA |
| `banco_sites.png` | Banco local de sites e aplicação ao gateway |
| `administracao_remota.png` | Inventário de catálogo obtido de sessão falsa no teste de interface |
| `integracoes.png` | Formulário de integração, sem equipamento conectado |
| `mapa_rede.png` | Mapa lógico e controles por IP/MAC em demonstração |
| `topologia.svg` | Topologia lógica ilustrativa, desenhada em vetor |

As imagens não comprovam compatibilidade com equipamentos ou computadores reais. A matriz de capacidades e os pré-requisitos do manual descrevem o alcance implementado.
