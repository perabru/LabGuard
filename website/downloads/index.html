Baixe estes dois executáveis.

As numerações são de produtos diferentes. Central 1.2 e Cliente 2.3 trabalham juntos; Rede 2.4.4 é outra edição.

PC DOS ALUNOS · CLIENTE 2.3

Proteção da estação

Arquivo de vínculo da Central na primeira instalação.

OS DOIS PROGRAMAS NO MESMO DOWNLOAD

Pacote completo pronto para uso

LabGuard-Gerenciado-Windows.zip

Contém os dois EXEs acima, instruções, relatório de testes e SHA-256. Extraia o ZIP e execute cada programa no computador correto. Não é um terceiro instalador e não instala tudo automaticamente.

Baixar pacote completo ZIP
Antes de ativar a limpeza

A remoção pode apagar jogos, saves e mundos permanentemente. Faça backup e teste uma estação primeiro. Baixar a atualização não a instala remotamente: atualize o administrador e cada cliente. Os EXEs não exigem Python instalado. Não desative o antivírus nem o UAC.

GUIA RÁPIDO · INSTALAR OU ATUALIZAR

Da instalação ao primeiro aviso.

1

Prepare a Central

Abra LabGuardTecnico.exe no PC administrador. Na primeira instalação, informe o IP real/reservado, a rede autorizada e uma senha. Para atualizar, use Instalar / reparar. Entre no painel local em http://127.0.0.1:8787/.

2

Vincule cada estação

Em Computadores → Vincular computador, gere um JSON individual. No PC do aluno, selecione-o no LabGuard-Jogos.exe e clique em Instalar e conectar. Para atualizar um cliente já vinculado, use Atualizar e manter vínculo.

3

Confira antes de considerar aplicado

Em Computadores, veja o contato recente e a confirmação de Sites. Em Sites rápidos, use Bloquear tudo ou os controles por site. Reabra os navegadores e teste na conta do aluno. Em Avisos e proteção, acompanhe os eventos.

“Bloquear tudo” não corta a internet inteira.

Bloqueia os endereços cadastrados na lista rápida e o YouTube. Termo, Friv, Poki (interpretação de “Poke”) e Chess.com já têm endereços cadastrados. Joguester está pendente de endereço: use Editar endereço para informar o link correto. O botão não ativa a desinstalação de jogos.

Documentação avançada de servidores

Cliente antigo 1.x, Jogos 2.1 independente e código-fonte

LabGuardCliente.exe 1.x é o cliente legado para a lista extensa de Sites e regras. Não é o mesmo programa que LabGuard-Jogos.exe 2.3; não oferece esta nova lista rápida e os mesmos avisos. A atualização 2.3 não substitui automaticamente uma instalação 1.x. Revise com a TI antes de manter dois agentes.

Jogos 2.1 é uma versão local independente anterior, sem este canal de avisos. Para a experiência gerenciada, baixe o par atual acima.

Source code (zip/tar.gz) nas versões do GitHub é somente o código-fonte. É voltado a auditoria/desenvolvimento e precisa de compilação; não é o download pronto para instalar.

Consultar código-fonte

A instalação está pronta quando o painel confirma.

Uma regra salva é uma solicitação. A confirmação por estação informa a aplicação da configuração. Faça o teste de navegação real antes de liberar o laboratório para uso.
