# Referências visuais do LabGuard

O site utiliza uma composição e código próprios, adaptados à identidade roxa, azul e amarela do LabGuard. As referências abaixo foram escolhidas pelo usuário em seus projetos anteriores e orientaram o tratamento dos componentes:

- Botões com profundidade, cantos suaves e resposta ao clique: [cssbuttons-io / nice-walrus-6](https://uiverse.io/cssbuttons-io/nice-walrus-6).
- Cards interativos com destaque de borda: [ElSombrero2 / tricky-robin-67](https://uiverse.io/ElSombrero2/tricky-robin-67).
- Cards arredondados e ações claras: [alexmaracinaru / white-octopus-62](https://uiverse.io/alexmaracinaru/white-octopus-62).
- Alternância de tema com sol e lua: [rishichawda / fluffy-robin-48](https://uiverse.io/rishichawda/fluffy-robin-48).
- Referência de movimento para estados de carregamento: [Nawsome / blue-dragon-70](https://uiverse.io/Nawsome/blue-dragon-70).

Não há dependência desses sites em tempo de execução. O JavaScript, os estilos e os vetores do LabGuard foram escritos para este projeto. A interface não copia textos de marketing ou identidade visual dos exemplos. As ilustrações de painel usam somente dados fictícios e estão identificadas como demonstração.

## Publicação

Arquivos estáticos, sem etapa de compilação ou bibliotecas externas. Publique o conteúdo desta pasta na raiz do GitHub Pages. Todos os caminhos de arquivos locais são relativos, inclusive os ícones SVG.

As URLs do projeto apontam para `https://github.com/perabru/LabGuard`. O botão de download consulta apenas a API pública de versões do GitHub. Quando encontra `LabGuard-Setup.exe`, usa a URL do arquivo retornada pelo GitHub; caso contrário, continua apontando para a página de versões e informa a necessidade de conferir sua disponibilidade.
